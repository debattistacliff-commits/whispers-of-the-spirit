WHISPERS OF THE SPIRIT 2.3 - WINDOWS INSTALLER
================================================

HOW TO INSTALL

1. Right-click the ZIP file and choose "Extract All...".
2. Open the extracted folder.
3. Double-click "Install Whispers of the Spirit.bat".
4. Wait for the success message. The application will open automatically.
5. Use the new "Whispers of the Spirit" shortcut on your desktop next time.

No administrator password should be needed. The application is installed only
for the current Windows user under the Local AppData folder.

IMPORTANT

- Keep the Application and support folders beside the installer BAT file.
- Always extract the complete ZIP before installing. Do not run the BAT from
  inside the ZIP preview window.
- If an existing installation is found, the installer creates a new versioned
  application folder. It does not delete or clean old installations.
- The installer uses copy-only operations. It never deletes recordings or user
  data.

OPTIONAL: XBOX 360 KINECT FOR THE SLS CAMERA

The SLS camera works with any webcam. If you also own an Xbox 360 Kinect (with
its PC power/USB adapter) or a Kinect for Windows v1, install the free
"Kinect for Windows Runtime 1.8" from Microsoft, plug in the Kinect, then choose
KINECT INFRARED or KINECT DEPTH at the top of the SLS camera window.

TROUBLESHOOTING

If Windows displays a security prompt, check that the ZIP came from someone you
trust. If installation fails, read the error shown in the installer window and
make sure the ZIP was fully extracted before trying again.
